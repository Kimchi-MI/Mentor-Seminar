# Шаблоны для лабораторной работы № 1
## «Развёртывание приложения в Kubernetes»

Здравствуйте! В этой папке — заготовки манифестов, которые вы будете
заполнять в ходе лабораторной работы.

**Как работать с шаблонами:**

1. Откройте файл, соответствующий текущему заданию (см. `../tasks/`).
2. Найдите места, отмеченные `<ВПИШИТЕ ...>` — рядом с каждым есть
   комментарий-подсказка.
3. Заполните пропуски. Не торопитесь подсмотреть ответ — сначала подумайте.
4. Проверьте манифест **до** применения в кластер:

```bash
kubectl apply -f pod.yaml --dry-run=client -o yaml
```

5. Применяйте и проверяйте по критериям из задания.

**Правила сдачи:** заполненные манифесты + отчёт (`lab-report.md`) —
в вашем репозитории. Отчёт без скриншотов из терминала не принимается.

**Если застряли:** вернитесь к материалам лекции, затем — к разбору
типичных ошибок в задании, и только потом зовите преподавателя.

Удачи!
